# workline: set notation, tree-sitter grammar + JS and Go semantics

`grammar.js` is the only definition of the syntax. `SPEC.md` covers what the
grammar cannot (value ranges, defaults, canonical form), and
`test/vectors.json` is the executable contract. JSDoc only, no TypeScript
syntax; `tsc --checkJs` is the type gate.

## Commands

```sh
npm install      # .gitignore ignores package-lock.json, so npm ci fails
npm run build    # tree-sitter generate + workline.wasm; first run downloads wasi-sdk
npx tsc
npm test         # node:test, vectors against workline.wasm
go vet ./bindings/go/ ./golang/
go test ./bindings/go/ ./golang/   # not ./...: node_modules can hold stray Go packages
swift build
```

## Layout

- `grammar.js` tree-sitter grammar (ESM). `src/` is generated from it: never edit by hand
- `queries/highlights.scm` editor highlighting
- `lib/index.js` JS package: `init()` loads web-tree-sitter + `workline.wasm`,
  then sync `parse`, `expand`, `serialize`. Reference semantics live here
- `golang/` Go package `workline` (`github.com/JakobMelchard/workline/golang`):
  `Parse`, `Expand`, `Serialize` on top of `bindings/go` (cgo). Hand-written, outside
  `bindings/` so `tree-sitter init -u` never touches it. JSON tags match `vectors.json`;
  `golang/vectors_test.go` runs the vectors like `test/vectors.test.js`
- `bindings/{c,go,swift}`, `Makefile`, `CMakeLists.txt`, `Package.swift`, `go.mod`
  generated by `tree-sitter init`; regenerate with `npx tree-sitter init -u`
- `workline.wasm` committed build output, shipped in the package. `web-tree-sitter.wasm`
  is copied from the pinned `web-tree-sitter` by `npm run build`, so Workers consumers
  can import the runtime from this package; keep that dependency pinned exactly

## Rules

- Grammar, spec, vectors, `lib/` and `golang/` change in the same commit. A syntax change
  without a vector is not done. Run `npm run build` and commit `src/` and
  `workline.wasm`; CI fails when `src/` is stale.
- Other languages reuse the grammar through the bindings (Go in `golang/`, Kotlin
  through KTreeSitter) and reimplement only the semantics, checked against `vectors.json`
  (exported as `@jakobmelchard/workline/vectors.json`).
- Nothing here may be copied from Liftosaur (AGPL-3.0). Borrow notation from
  its public docs only, never its grammar files or source.
- Serialize keeps error lines verbatim so a bad cell survives a round trip
  through an app untouched.
- The grammar is ABI 15, so `go.mod` needs go-tree-sitter >= v0.25.0; older
  versions load the language but every parse fails. Keep that after `init -u`.
- cgo does not track `src/parser.c` (bindings/go `#include`s it from outside the
  package), so after regenerating `src/` run `go clean -cache` before `go test`,
  or Go tests the stale parser.
- Versions live in `package.json` and `tree-sitter.json`; bump both and tag.
  Consumers pin tags.
